## Mobile Posting (Issue -> Post)

1. Move to `Issues`
2. Write to use `Blog Post` Template
3. Create issue

Template fields: `excerpt`, `categories`, `tags`, `date`, `last_modified_at`, `content` (`title`은 GitHub `Add a title` 사용).
