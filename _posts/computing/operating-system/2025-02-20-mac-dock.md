## 서론

- 보통 알려진 방법으로는 아래의 명령어와 같이 애니메이션 자체의 시간을 짧게 하여 Dock이 바로 나타나게끔 하는 것이었다.
  - `defaults write com.apple.dock autohide-time-modifier -float 0.25; killall Dock`
- 하지만, 애니메이션은 그대로 살리고 답답함만 없애는 방법도 존재한다.

## 해결

```bash
defaults write com.apple.dock autohide-delay -float 0; killall Dock
```

- 위 명령어는 Dock이 나타나기까지의 지연 시간만 제거한 명령어이므로, 애니메이션은 살리면서 답답함만 싹 제거할 수 있다.

## 원복

```bash
defaults delete com.apple.dock autohide-time-modifier; defaults delete com.apple.dock autohide-delay; killall Dock
```

- 혹시나 다시 되돌리고 싶으면 이 명령어를 실행하면 된다. (동시 적용)
