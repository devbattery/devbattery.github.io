- LeetCode 27. Remove Element - Python 풀이
  - `val`과 다른 `nums[i]`의 개수 찾는 문제
  - `nums[k]`에는 우선적으로 `val`고 다른 것들이 먼저 오게 됨

```python
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        k = 0
        for i in range(len(nums)):
            if nums[i] != val:
                nums[k] = nums[i]
                k += 1

        return k
```
