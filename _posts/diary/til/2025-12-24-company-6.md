- LeetCode 26. Remove Duplicates from Sorted Array - Python 풀이
  - `nums[i]`가 `nums[i - 1]`과 다를 때만 새로운 `nums` 원소가 되는 거라 생각하면 된다. 왜냐면 정렬이 되어 있으니까!
  - 어제 풀었던 문제와 비슷하게 k가 움직인다고 생각을 해야 안 헷갈림

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        k = 1
        for i in range(1, len(nums)):
            if nums[i] != nums[k - 1]:
                nums[k] = nums[i]
                k += 1

        return k

```
